Admin login

This page is separate from the game. The first password is admin unless ADMIN_PASSWORD is set.

Drag the map to move it, and scroll to zoom. Draw a zone or the world edge. A zone that crosses the coast is cut back to the shoreline. Chop tree and Mine rock can be gathered. Tree and Rock are scenery and cannot. Place a camp, then choose its buildings. Every camp has an innkeeper. Shop, trainer, and quest giver are optional. The Road tool connects two camps. Click the first camp, add bends if you need them, click the next camp, then Finish outline. Straight or organic applies to each new stretch. Erase removes the single tree, rock, herb, or camp you click. Undo takes back the last change.

A zone can override hit points. Blank uses this formula.

Select a zone, then create the quest. The giver is an NPC from that zone. Kill and gather quests use the zone's mob. A gather item can be one placed in the zone. Export quests and items, then open the file in Google Sheets with File, Import, Upload. Name and a short description come first. Game id is the last column.

A dungeon is a short cave. Place its portal on the world map. Draw the route on the route map: the first point is the entrance inside, the last point is the end. Rocks, roots, and pillars sit on the edge and block the path. Quests marked with this dungeon are finished inside and handed in to the end NPC.
